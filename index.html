Instalasi

Mulai dalam hitungan detik.

Pilih jalur instalasi yang paling sesuai: Python Package via PyPI, ekstensi editor via Open VSX, atau Termux untuk Android.

PyPI — Python Package

$ pip install streamlit-launcher

Jalankan di terminal, notebook, atau skrip otomatis. Mendukung Python 3.7+ dan Streamlit 1.28+.

Open VSX — Ekstensi Editor

$ ovsx install dwidevelopes.streamlit-launcher

Untuk VS Code, VSCodium, Gitpod, dan editor turunan VS Code lainnya.

Termux — Android

Instalasi lengkap di Termux tersedia melalui skrip otomatis. Cocok untuk menjalankan launcher langsung dari ponsel.

Panduan Termux

Development

$ pip install streamlit-launcher[dev]

Untuk kontribusi: pytest, black, flake8, mypy, dan pre-commit.

FAQ

Pertanyaan yang sering diajukan.

Ringkasan cepat sebelum kamu mengunduh dan menjalankan Streamlit Launcher.

Apakah Streamlit Launcher gratis?

Ya. Streamlit Launcher dirilis dengan lisensi MIT, sehingga gratis digunakan, dimodifikasi, dan didistribusikan sesuai ketentuan lisensi.

Apakah saya perlu bisa coding?

Tidak. Streamlit Launcher dirancang sebagai platform no-code. Kamu bisa mengunggah CSV atau Excel, memilih model, dan menjalankan analisis langsung dari antarmuka.

Platform apa saja yang didukung?

Windows, macOS, dan Linux. Tersedia juga dukungan Termux untuk Android melalui panduan instalasi di README.

Bagaimana cara memperbarui ke versi terbaru?

Jalankan pip install --upgrade streamlit-launcher di terminal. Untuk ekstensi Open VSX, perbarui melalui editor atau gunakan perintah ovsx install kembali.

Di mana saya bisa melaporkan bug atau meminta fitur?

Gunakan halaman Issues untuk melaporkan bug, atau kirim pull request / diskusi melalui repositori GitHub resmi.
